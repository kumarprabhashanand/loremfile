    For agents

    Read llms.txt for a short summary, llms-full.txt for every file, or manifest.json for sizes, hashes and measured properties. Each format also has its own list at /{format}/index.json.

    Rules

    • Stable URLs. The bytes at a published path do not change; a fix is a new path.
    • Rate limit. Stay under 30 requests per second per IP. In CI, download once and cache.
    • Licence. Every file is CC0 1.0: use it for anything, no credit needed.
    • Host. If this host is ever unavailable, the repository README states the current canonical host.
