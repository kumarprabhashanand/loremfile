Our sample files are measured: the manifest records what each one holds. Here each is handed to the standard-library readers of the supported versions of each runtime, and what the reader said is set beside what the manifest says. A cell is one reader, one runtime version and one file; its outcome is a word, never a colour.

The runtimes are the latest supported ones, with the versions they resolved to recorded and none pinned: the question is what a fresh install does. A disagreement is as likely to be our measurement as the library's, and both are worth finding.
